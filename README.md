# 🎁 Amigo Secreto

Una aplicación web interactiva para realizar sorteos de amigo secreto de manera fácil y divertida.

## 📋 Descripción

Esta aplicación permite a los usuarios crear listas de participantes y realizar sorteos aleatorios para determinar quién será el "amigo secreto" de cada persona. Ideal para celebraciones navideñas, cumpleaños, intercambios de regalos y cualquier evento donde se requiera un sorteo justo y transparente.

## ✨ Funcionalidades

### 🔸 **Agregar Participantes**
- Campo de texto para ingresar nombres de amigos
- Botón "Adicionar" para agregar nombres a la lista
- Los nombres se muestran instantáneamente en una lista visible

### 🔸 **Validación de Datos**
- Verificación de campos vacíos
- Alertas informativas para guiar al usuario
- Validación de nombres duplicados

### 🔸 **Visualización de Lista**
- Lista dinámica de participantes agregados
- Interfaz clara y organizada
- Fácil seguimiento de quién está incluido en el sorteo

### 🔸 **Sorteo Aleatorio**
- Botón "Sortear Amigo" para realizar la selección
- Algoritmo de selección completamente aleatoria
- Resultado mostrado claramente en pantalla

## 🛠️ Tecnologías Utilizadas

- **HTML5** - Estructura de la aplicación
- **CSS3** - Diseño y estilos responsivos
- **JavaScript** - Lógica de funcionamiento y interactividad
- **DOM Manipulation** - Actualización dinámica de la interfaz

## 🚀 Cómo Usar

1. **Agregar Participantes:**
   - Escriba el nombre de un amigo en el campo de texto
   - Haga clic en el botón "Adicionar"
   - Repita el proceso para todos los participantes

2. **Realizar el Sorteo:**
   - Una vez que tenga todos los nombres en la lista
   - Haga clic en el botón "Sortear Amigo"
   - El resultado aparecerá en pantalla

3. **Repetir Sorteo:**
   - Puede realizar múltiples sorteos con la misma lista
   - Cada sorteo es completamente independiente y aleatorio
